📖 User Guide

🚀 Getting Started

This system tracks livestock shipments entering animal shops in Abu Dhabi. It manages Accepted, Rejected, and Washed shipments, plus a detailed rejection archive searchable by animal ID.

📝 Data Entry Tab

Vehicle & Driver

  • Enter the plate number and select the emirate. If it matches a saved provider, driver details auto-fill.
  • Date & Time are auto-filled. Click 🔄 Now to refresh.

Health Certificate

  • Required only for non-Local breeds (Australian, Somali, Pakistan, Iran, etc.). Local shipments can skip it.
  • Total in Certificate is optional — if filled, the system tracks the remaining balance across shipments using the same certificate.

Species & Sub-breeds

  • Add one row per species/breed combination. Click ➕ to add another, ✖ to remove.

Accept vs Reject

  • Accept: shipment goes into the Wash Queue.
  • Reject: rejection reason is required. You can optionally register individual animal IDs.

🐏 Animal IDs (Rejected)

Three ways to enter rejected animal IDs:

  • Individual: one row per animal.
  • Sequential Range: enter prefix, from/to numbers, padding, suffix — generates IDs automatically.
  • Paste List: paste from Excel or Word, one per line.

Within the same shipment, duplicate IDs are blocked. Across shipments, you get a warning but can proceed.

🚿 Wash Queue Tab

  • Pending: accepted shipments awaiting wash.
  • Select rows → click ➡️ Move to Washed.
  • Washed vehicles are recorded with a timestamp.

🔍 Rejection Archive

  • Search Animal ID: full or partial — shows full history if found.
  • Left table: rejected shipments. Click 👁️ View IDs to see the animal IDs in that shipment.
  • Right table: all rejected animal IDs with filters (species, breed, ID).

💾 Data Storage & Backup

Everything saves automatically to your browser after 1 second of inactivity. If you refresh or close the tab, all data is restored when you come back.

⚠️ Data is stored on this device only. Use 📤 Export to save a full backup to a JSON file, or 📥 Import to merge data from another device or restore a backup.

📤 Export / Import (JSON)

  • 📤 Export: downloads all data (accepted + rejected + washed + providers) to a single JSON file. Use this regularly as a backup.
  • 📥 Import: opens a file picker. Choose a previously exported JSON file, then pick one of three modes:
    • Merge (default): adds new records only, skips existing ones
    • Replace All: deletes current data first, then imports
    • Merge & Overwrite: adds new + replaces existing with imported version

💡 Tip: Use Export + Import to combine records from multiple devices (each entry person exports their data, then you import all files into one master copy).

🔐 Admin Password

Certain actions (deleting records) require the admin password. Contact your administrator if you need access.
