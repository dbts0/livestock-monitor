📖 User Guide

🚀 Getting Started

This system tracks livestock shipments entering animal shops in Abu Dhabi. It manages Accepted, Rejected, Sprayed, Washed shipments, and now includes a Live Inventory to track the actual animals inside each shop.

📝 Data Entry Tab

  • Quick Select Vehicle: Auto-fills saved provider details.
  • Health Certificate: Required only for non-Local breeds.
  • Animal IDs: Optional registration for accepted or rejected animals.

🚿 Vehicle Spray/Wash Tab

  • Pending: Newly accepted shipments waiting for spraying or washing.
  • Animal Spraying: Shipments that have been sprayed.
  • Washed: Fully washed vehicles.
  • You can move records step-by-step or skip directly to washed. Select records to export them individually.

🏪 Live Inventory Tab

  • Shows a visual grid of all shops grouped by location.
  • Click any shop card to see details, deduct animals (Slaughter/Death/Sale), or transfer them to another shop.
  • Deductions and Transfers are recorded in a movement log.

🔍 Search & Archive Tab

  • Search by Animal ID, Health Certificate, or use filters (Species, Breed, Shop, Date).
  • View animal histories and shipment details.

✏️ Editing & Admin

  • Click ✏️ Edit next to a record to modify it (requires Admin Password: 2102258).
  • Deletions also require the password.

💾 Backup

Use 📤 Export All to save a full JSON backup (including inventory movements). Use 📥 Import All to restore or merge data.
